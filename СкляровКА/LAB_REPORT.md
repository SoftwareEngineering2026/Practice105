# Лабораторная 5. Docker Compose

Автор: Скляров Константин Александрович, группа РИМ-150975к.
Проект: https://github.com/dyda5505-cloud/textlab-course. Полный комплект исходных файлов находится в этом каталоге.

Приложение выполняет асинхронный анализ текста: число символов, слов, уникальных слов
и top-10 по частоте. Nginx отдаёт frontend (HTML/JavaScript) и проксирует HTTP API
на backend:8000. Backend — Flask под WSGI-сервером Gunicorn. Отдельный worker
получает задания из SQLite на общем томе и сохраняет результаты.

Внешняя точка входа одна — Nginx на localhost:8080. Сервисы используют внутреннюю
сеть Docker и том jobs. POST /api/jobs возвращает 202 и идентификатор задания;
GET /api/jobs/{id} возвращает статус и результат. Работа worker отделена от backend.
SQLite BEGIN IMMEDIATE атомарно захватывает задание; потерянные задания
после сбоя обработчика возвращаются в очередь через 5 минут.

Запуск: `docker compose up --build`. Открыть http://localhost:8080.
Проверка после запуска: `python tools/smoke.py`.

Сборка контейнеров и полный HTTP-путь Nginx → Gunicorn → очередь → worker → результат
проверены на Ubuntu runner: https://github.com/dyda5505-cloud/textlab-course/actions/runs/37193914473, job test-build. Проверка завершилась успешно.
Вывод: Compose позволяет одной командой развернуть сервисы, сеть и постоянное хранилище;
асинхронная очередь освобождает API от выполнения обработки текста.
